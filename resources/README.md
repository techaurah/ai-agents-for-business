# Resources

Curated resources for AI Agents for Business, grouped by theme.
Lessons link to the items they use; this page is the full shelf.
Official documentation first, because it ages best. If a link here
breaks, that is a lesson problem: please open an issue so it gets
fixed for everyone.

New to a word? The [glossary](glossary.md) defines every term this
course uses, in plain language.

## Learning agents as a builder (the companion shelf)

- [Agentic AI for Beginners](https://github.com/techaurah/agentic-ai-for-beginners): Course 1 of this programme. How agents work inside: loops, tools, memory, evaluation, MCP. Take it when a lesson here makes you want the builder depth.
- [AI Automation with n8n](https://github.com/techaurah/ai-automation-with-n8n): Course 2. Workflow automation, including the BrightSmile Dental examples this course continues.
- [Build MCP Servers](https://github.com/techaurah/build-mcp-servers): Course 3. How the tool layer agents use gets built, secured, and published.
- [Microsoft, AI Agents for Beginners](https://github.com/microsoft/ai-agents-for-beginners): the large free builder curriculum surveyed in RESEARCH.md.
- [Hugging Face AI Agents Course](https://huggingface.co/learn/agents-course/unit0/introduction): the free framework tour (smolagents, LlamaIndex, LangGraph) with a certificate.
- [Google and Kaggle, 5 Day AI Agents Intensive](https://www.kaggle.com/learn-guide/5-day-ai-agents): five days of whitepapers and codelabs, strong on agent quality.

## Frameworks and platforms, in their own words

- [LangChain documentation](https://docs.langchain.com): LangChain and LangGraph, the stateful orchestration layer Lesson 09 discusses.
- [CrewAI documentation](https://docs.crewai.com): role based crews and flows, the readable prototype route in Lesson 09.
- [Model Context Protocol documentation](https://modelcontextprotocol.io): the protocol that lets agents use tools built by others; Course 3 teaches building that layer.
- [Python documentation](https://docs.python.org/3/): the standard library every calculator, simulator, and checker in this course is built on.

## Rules and risk, from primary sources

- [EU AI Act, Regulation (EU) 2024/1689](https://eur-lex.europa.eu/eli/reg/2024/1689/oj): the regulation itself. Lesson 17 teaches the deployer slice; this is where a professional adviser will start.
