# Exercise for Lesson 28: Stress test the plan: red team your own deployment

Run the stress test on your plan. Script at least two cases per stressor from the lesson, adapted to your process, and score them with a colleague if one is available. Fix gaps in the plan, rerun their stressors, and write the residue page: the risks you consciously carry, each with the trigger that reopens it. File the scored sheet as the plan's final annex.
