# Visual guide

Every core idea in this course has a diagram. They are drawn in one
style so the shapes stay familiar: navy boxes are the main actor or
step, light boxes are supporting steps, amber boxes are gates where
a human or a safety check decides. Each diagram also lives inside
the lesson it belongs to.

| Diagram | What it teaches | Used in |
|---|---|---|
| [course-map.svg](course-map.svg) | The whole course on one page: 9 modules, one decision, one plan | README |
| [three-kinds.svg](three-kinds.svg) | Agent, chatbot, and workflow, and who decides each step | Lesson 01 |
| [opportunity-matrix.svg](opportunity-matrix.svg) | Volume against judgement: where agents fit and where they do not | Lessons 02, 03 |
| [readiness-triangle.svg](readiness-triangle.svg) | Data, access, people: all three sides or not yet | Lessons 05 to 07 |
| [three-routes.svg](three-routes.svg) | Build, buy, managed service, honestly compared | Lesson 08 |
| [oversight-ladder.svg](oversight-ladder.svg) | Act, draft, ask, escalate: autonomy by risk | Lessons 15, 26 to 28 |
| [capstone-flow.svg](capstone-flow.svg) | Audit, pilot, supervise, score: the deployment plan in order | Lessons 26 to 29 |

Diagrams are generated by [generate_visuals.py](generate_visuals.py)
so the set stays consistent. Edit the script, rerun it, and commit
the SVGs it writes. Every use carries descriptive alt text, so
screen-reader learners and search engines get the same content as
sighted readers.
