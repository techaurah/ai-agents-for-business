# Solution for Lesson 16: Security basics: what an agent must never be able to do

The worked list's teaching moment is the fifth row. BrightSmile's first instinct for wrong data at scale was to instruct the agent to be careful, which is no control at all against the actual mechanism: the agent will quote the approved list faithfully, and if the list is wrong, fidelity is the problem. The real controls are upstream and downstream of the model: one canonical list with one owner (Lesson 05), sampled human review of real replies each morning (Lessons 13 and 21), and a rehearsed correction, who contacts affected customers, with what wording, owned by the operator. Notice that none of those mention AI. Most agent security at this scale is ordinary operational discipline, applied to a faster typist.
