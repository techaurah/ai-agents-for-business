# Capstone showcase

Finished agent deployment plans from learners of AI Agents for Business.
This table is the course's completion artifact: no certificates,
just plans anyone can open, read, and judge, each one honest about
the business it was written for (fictionalised where privacy needs it).

## How to get your plan indexed

1. Finish the capstone (Lessons 26 to 29). Your plan must be in a public repository of your own, with the four sections Lesson 26 fixes (readiness, pilot, oversight, scorecard), and with every business number stated as a worked example with assumptions, never as a market claim. Remove or fictionalise any real customer data before publishing.
2. Fork this repository and add **one row** to the table below: your name or GitHub handle, a link to your plan repository, and one line describing the process and the business type.
3. Open a pull request titled `Showcase: <your handle>`. Small, single-purpose PRs like this merge directly under the course's [two-tier contribution rule](../CONTRIBUTING.md); you do not need to open an issue first.
4. A maintainer checks that the link works, the four sections are present, and the numbers carry their assumptions. Complete and honest beats polished.

One row per learner. If you run the pilot and update the plan, update your row with a second PR.
