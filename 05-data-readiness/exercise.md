# Exercise for Lesson 05: Data readiness: what the agent may read, and whether it is true

Build the inventory for your mapped process. List every source the agent would read or write, find its owner, sample it against reality (open five records, check them against what you know), and grade it with a limit for every partial. For any source you cannot find an owner for, grade it not ready and write down why; ownerless data is the single most common readiness failure.
