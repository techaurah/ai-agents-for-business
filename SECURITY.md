# Security policy

## Reporting a vulnerability

If you find a security problem in this repository, for example a lesson that teaches an unsafe access pattern, example code that leaks credentials, or a template that invites learners to paste real customer data into a public fork, please do not open a public issue with the details.

Report it privately through the contact form at [techaurah.com](https://techaurah.com), with "AI Agents for Business course security" in the message. We aim to acknowledge reports within three working days and to fix or annotate confirmed problems in the affected lesson.

## Scope notes

- This is a teaching repository. Every example business is fictional, every dataset is invented for the lesson, and learners are told repeatedly never to put real customer data in a fork.
- Never commit real API keys, tokens, customer lists, or personal data to your fork. If you accidentally commit a secret, rotate it immediately; deleting the commit is not enough.
- Lessons 16 and 17 teach the security and privacy basics this course can responsibly teach. They are starting points for a conversation with a qualified professional, not legal or security certification.
