# Solution for Lesson 27: Build the plan: readiness, pilot, oversight

The two contradictions in BrightSmile's build record deserve their fame. The diary write assumption survived from an early vendor conversation into the job description, three lessons after the access plan had restricted the diary to read only for the pilot; nobody lied, the document simply aged unevenly, which is what cross checks exist to catch. The Sunday rota gap was subtler: the ask rung's destination was named and willing, and their rota did not include Sunday afternoons, when the pilot (closed hours) was busiest. Both fixes took minutes in the plan and would have taken an incident in production. If your build finds zero contradictions, run the checks again with a colleague reading the opposing sections aloud; seams hide from their own authors.
