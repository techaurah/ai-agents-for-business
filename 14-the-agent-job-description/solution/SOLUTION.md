# Solution for Lesson 14: The agent job description: task, tools, limits, tone

The worked page's most consequential line is easy to miss: the purpose names the baseline leak (unanswered and overnight enquiries) rather than a capability. That phrasing disciplines everything downstream, because Lesson 22's scorecard will grade the agent on that purpose, and any feature that does not serve it is scope creep with a purchase order. Compare the nevers list with Lesson 03's no list: they rhyme but are not copies. The no list refuses whole jobs for the business; the nevers fence the approved job from inside. Both documents will be attached to the capstone plan, and a reviewer should be able to trace every never to a no list test or an access band. If a never cannot be traced, it is probably a preference; mark it as tone instead, and keep the nevers list short enough to be sacred.
