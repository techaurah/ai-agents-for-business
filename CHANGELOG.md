# Changelog

All notable changes to this course are recorded here. The format
follows Keep a Changelog, and the course versions follow semantic
versioning for the course as a whole.

## [1.0.0] - 2026-11-06

### Added

- Complete course: 30 lessons (00 to 29) across 9 modules, from
  telling an agent apart from a chatbot and a workflow, to a
  complete agent deployment plan you scope, pilot, supervise,
  and score yourself.
- BrightSmile Dental, the running fictional business: a lead
  response agent is chosen, costed, piloted, and supervised
  across the whole course, and the capstone generalises it to
  a process of the learner's choosing.
- Plain Python simulators and calculators in every lesson:
  a lead response simulator, a cost worksheet calculator, an
  escalation policy checker, a readiness audit, and a pilot
  scorecard, all on the standard library.
- Tools for contributors: a course validator (JSON examples,
  capstone plan completeness) and a relative link checker,
  both wired into CI with per lesson smoke tests.
- Visual set in the TechAurah Academy style: course map,
  opportunity matrix, readiness triangle, build buy managed
  comparison, oversight ladder, and capstone flow diagrams,
  generated by a committed script.
