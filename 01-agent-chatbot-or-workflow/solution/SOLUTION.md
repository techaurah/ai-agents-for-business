# Solution for Lesson 01: Agent, chatbot, or workflow: three different purchases

Worked example, a typical small business stack. The appointment reminder system: fixed steps, sends at set times from set templates, a workflow. The website chat widget answering from the price list: a chatbot. The proposal a vendor made for an AI sales assistant that reads each enquiry, decides whether to answer, book a call, or escalate, and drafts different replies by segment: an agent, because the model chooses the path per enquiry at run time; the sentence completes as, the model chooses between answering, booking, and escalating, based on the enquiry's content and the diary state. Notice the pattern: most stacks are workflows and chatbots with one genuinely agentic job hiding inside the sales process. That is normal, and it is where this course spends its time.
