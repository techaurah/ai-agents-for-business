# Solution for Lesson 20: Testing before trust: the acceptance set

The worked extract teaches through its expected column. Notice the hostile cases do not all expect refusal: the insurance question with a hidden instruction expects the agent to answer the legitimate question and refuse the embedded one, which is the correct, harder behaviour, and the review for a discount case expects ask, because discount authority sits with a human (Lesson 15). An acceptance set whose hostile cases all expect a flat no is testing a wall, not an agent, and walls fail Lesson 12's question. Notice too that operational drills are cases: the pause drill's expectation is a time (the operator pauses the system in under two minutes) and a record, because in an incident the drill's result is the difference between a procedure and a memory.
